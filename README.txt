
مشروع متجر Bags بسيط — Python + Flask + SQLite

التشغيل على الكمبيوتر:
1) ثبّت Python.
2) افتح Terminal داخل مجلد المشروع.
3) نفّذ:
   pip install -r requirements.txt
4) ثم:
   python app.py
5) افتح المتصفح على:
   http://127.0.0.1:5000

صفحة الطلب:
http://127.0.0.1:5000/

صفحة مشاهدة الطلبات (للتجربة فقط، بدون تسجيل دخول):
http://127.0.0.1:5000/admin

مهم قبل نشره على الإنترنت:
- أضف تسجيل دخول حقيقي للوحة الإدارة.
- لا تعرض بيانات الزبائن للعامة.
- استخدم HTTPS.
- أضف التحقق من أرقام الهاتف والبيانات.
- استبدل رسم الحقيبة بصورة منتجك الحقيقية.
- أضف نظام توصيل/شركة شحن إذا أردت أتمتة الطلبات.
